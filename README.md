# Página de Local Turístico 🌍

Este projeto é o resultado do primeiro desafio prático da **Formação Full-Stack da Rocketseat**. O objetivo central foi a criação de uma página web focada em um local turístico, realizando a transposição de um layout profissional do Figma para código real.

## 🚀 Sobre o Projeto

O desafio consistiu em aplicar fundamentos sólidos de desenvolvimento web para construir uma interface fiel ao design proposto, priorizando a organização e a acessibilidade.

## 🛠 Tecnologias e Conceitos Aplicados

Durante o desenvolvimento, foquei em pilares essenciais para uma base sólida em Front-end:

* **HTML5 Semântico:** Estruturação de dados garantindo acessibilidade e melhor indexação.
* **CSS:** Estilização com foco em tipografia, harmonia visual e precisão de layout.
* **Fidelidade ao Design (Pixel Perfect):** Implementação rigorosa baseada no protótipo do Figma.
* **Boas Práticas:** Organização de pastas e nomenclatura de classes para um código limpo e escalável.

## 📈 Aprendizado

Este projeto foi fundamental para conectar a teoria acadêmica de Engenharia de Software com a implementação técnica. Entender a organização dos elementos em página é o passo inicial para a construção de sistemas futuros mais complexos utilizando JavaScript e Node.js.
